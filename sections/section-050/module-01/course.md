# Placement Rules And Node Eligibility

This module develops placement Rules And Node Eligibility. It connects the intended application behavior to declared resources and observed conditions.

## Learning Goals

- Explain scheduling filters and preferences.
- Compare required and preferred affinity.
- Interpret taints and tolerations.
- Diagnose eligibility separately from available capacity.

## Before You Start

Use the module playground for guided practice. Graded exercises use independent environments and follow the readings they practise.
