# Admission And Resource Constraints

This module develops admission And Resource Constraints. It connects the intended application behavior to declared resources and observed conditions.

## Learning Goals

- Explain defaults, quota and resource requirement admission.
- Distinguish policy rejection from scheduler placement.
- Evaluate complete container resource needs.
- Interpret security profile enforcement and exceptions.

## Before You Start

Use the module playground for guided practice. Graded exercises use independent environments and follow the readings they practise.
