# Understand application deployments and how to perform rolling update and rollbacks

This section covers understand application deployments and how to perform rolling update and rollbacks. You will study Rolling Replacement And Recovery. The lessons explain the responsible components, configuration relationships and failure cases relevant to application development.

Each module begins with its goals and ends with a summary. Reusable YAML knowledge checks follow the section summary and are registered separately for future presentation.

## Learning Outcomes

- Identify Deployment template changes and revisions.
- Calculate rolling-update limits.
- Explain health and capacity effects on progress.
- Evaluate rollback compatibility and external state.
