# Understand the primitives used to create robust, self-healing, application deployments

This section covers understand the primitives used to create robust, self-healing, application deployments. You will study Reconciliation And Application Health. The lessons explain the responsible components, configuration relationships and failure cases relevant to application development.

Each module begins with its goals and ends with a summary. Reusable YAML knowledge checks follow the section summary and are registered separately for future presentation.

## Learning Outcomes

- Explain owner-driven replacement and desired state.
- Distinguish process startup from useful service.
- Choose health checks with appropriate recovery actions.
- Identify dependencies that replacement cannot repair.
