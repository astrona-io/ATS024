# Use ConfigMaps and Secrets to configure applications

This section covers use ConfigMaps and Secrets to configure applications. You will study Configuration And Confidential Input Delivery. The lessons explain the responsible components, configuration relationships and failure cases relevant to application development.

Each module begins with its goals and ends with a summary. Reusable YAML knowledge checks follow the section summary and are registered separately for future presentation.

## Learning Outcomes

- Choose file or environment delivery for configuration.
- Explain namespace and key references.
- Distinguish input updates from application reload.
- Evaluate confidentiality, indirect access and rotation.
